# 加成到底记在「颜料」上还是「地块」上

这个问题反复出现，这里把每次证据和时间点记全，避免重复讨论。

## 结论（2026-11-23 定案）

**加成记在颜料上。** 模型已按此实现：``Paint.bonus_level``。

用户 2026-11-23 明确要求「把 buff 改成颜料加成」，并给出了炸毁场景的实机口径。
解包资源（见 ``docs/s8_bonus_resource_evidence.md``）也支持这个结构：客户端的地块
（``Plot``）只有 ``RawLevel`` / ``FacadeLevel`` 和一张来源清单 ``OriItemList``，
每条来源指向一个**颜料实例** ``UniqueId``，**没有**「地块自己攒了多少级」这种字段。

### 三条规则（用户 2026-11-23 口述，实机口径）

**规则一：普通背包颜料被炸毁 → 加成随颜料一起销毁。**

强制完成把一枚普通背包颜料炸掉（地块变失色），恢复后是**全新空白地块，无任何
残留加成**。

**规则二：初始颜料的「范围」和「笔触效果」留在锚点地块上。**

举例：第 N 枚初始颜料是「怪物·幽灵」，调色目标=玩法，调色效果=提升1级，
笔触效果=堆砌·全图相同内容颜料提升2级。

1. 落下去 → 全图幽灵 +2；
2. 强制完成把它炸毁 → **地图上其他幽灵 -2**（因为锚点格上已经没有幽灵了）；
3. 失色恢复成空白，装一枚「存活」→ **全图存活玩法 +2**（笔触效果改挂到存活上）。

所以被炸毁的初始颜料，**范围和笔触效果都还在**。这就是 ``Tile.aura_amount`` 的
语义：强度挂在地块上，作用对象 = 「这一格当前那枚颜料」的同种颜料。

调色效果在不在，用户说「可能需要深挖，或者**暂定为在**」。当前实现按「在」处理
（加成已经兑现到目标颜料身上，不会因为来源颜料被炸而回退）。

**规则三：一枚初始颜料可以融合两种效果。**

同时拥有 2 个调色效果、2 个笔触效果、2 个作用范围。这条还没实现，记在下面的
「待做」里。

### 和旧的「记地块」结论为什么不冲突

旧文档（2026-11-22）记的实机样本是「替换不影响加成」：颜料被改写（转成别的颜料）
后仍吃到此前积累的 +2/+1，显示 6 级。那不是反例 —— 改写内容时**颜料实例还在**，
加成当然跟着它走。

真正能区分两种记法的只有**销毁**：那时「记颜料」丢加成、「记地块」保留。用户
2026-11-23 给了销毁场景的口径（规则一），答案是**丢**。

### 2026-11-23 炸毁场景（用户口述，规则一 / 规则二）
见上面「三条规则」。

### 2026-11-22 19:5x（同一局内，用户口述）
局面：遇到一枚 3 级初始颜料，词缀是「范围内转为同等级的颜料」，把两枚初始颜料
的等级都转化了。

* 其中一枚背包颜料**转化后依旧是 +3**；
* 左边的初始颜料显示：`相邻的玩法颜料提升1级` ×2 + `对角斜向的玩法颜料提升1级`，
  合计 +3，等级 6 = 3 + 3，与「3 级本体 + 3 级加成」吻合；
* 宝箱是 **+5**，没有受初始颜料被改变的影响。

→ 说明加成不随颜料的**等级/内容改写**而消失（改写 ≠ 销毁，颜料实例还在）。

### 更早的观察
用户点开一枚已放置颜料，浮窗里列出的是**其它初始颜料给它的调色效果**
（`使横向的玩法颜料提升1级` / `使纵向的玩法颜料提升1级`）。解包资源里这段提示框的

与观察一致。

## 代码现状（2026-11-23 改造后）

* ``Paint.bonus_level`` —— 颜料自己的等级加成。``tile_bonus_level(tile)`` 读它，
  地块上没有颜料就是 0。
* ``Tile.aura_amount`` —— 笔触光环的**强度**，挂在锚点地块上，与颜料生命周期无关。
* ``game_model._carried_tile_buffs`` —— 帧间继承：**上一帧这一格有颜料**才继承
  那笔加成；断帧（失色/空白）就归零。不比较颜料种类，因为转化也要继承。
* ``game_model._tile_with_upgrade(as_bonus=True)`` —— 写 ``Paint.bonus_level``。
* ``level_reconcile._cover_intermediate`` —— 覆盖类笔触改内容不改实例，加成跟着走。
* ``game_model._randomize_scope_paints`` —— 同理，转化不丢加成。
* ``fast_vision._tile_buffs`` —— 回填快照时读 ``Paint.bonus_level``。

## 待做

* **规则三（一枚颜料融合两种效果）**：``CurrentPaintRule`` 目前只有一个
  ``direction`` + ``extra_directions`` 和一个 ``upgrade_amount``。要支持
  「2 个调色效果 + 2 个范围 + 2 个笔触效果」需要把这三项都改成列表。
* **调色效果在炸毁后是否保留**：用户说「暂定为在」，当前实现如此。若日后有反例，
  需要让「来源颜料被销毁」时把那笔加成从目标颜料上撤掉 —— 那要求给它记
  ``source_key``（见 ``docs/s8_bonus_resource_evidence.md`` 里的 ``UniqueId``）。
