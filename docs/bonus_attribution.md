# 加成到底记在「颜料」上还是「地块」上

这个问题反复出现，这里把每次证据和时间点记全，避免重复讨论。

## 结论（2026-11-23 定案）

**只有一种东西：等级加成。区别只在来源。**

```
最终等级 = 颜料基础等级 + 调色效果加成 + 笔触效果加成 + 光环加成
             （背包/初始自带）  （初始颜料范围）  （词缀「额外提升」）（全图同内容）
```

用户 2026-11-23 原话：「提升1级和额外提升1级都是涨等级，都是加成，只是区分来源而已，
并不特殊地方」。所以代码里**没有**「这笔改等级、那笔记加成」的分叉 —— 一律写
``Paint.bonus_level``，来源只额外记在 ``Paint.bonus_parts`` 里供界面说明用。

这也是 c4r5 实机样本的读法：两笔调色效果（+2、+1）点开地块，游戏提示的是 **+3 加成**，
不是把基础等级改成了 6。

**加成挂在颜料上**，所以颜料不在（空白 / 虚空 / 失色）就没有加成。依据是解包资源
（见 ``docs/s8_bonus_resource_evidence.md``）：客户端的地块 ``Plot`` 只有
``RawLevel`` / ``FacadeLevel`` 和一张来源清单 ``OriItemList``，每条来源指向一个
**颜料实例** ``UniqueId``，**没有**「地块自己攒了多少级」这种字段。

### 三条规则（用户 2026-11-23 口述，实机口径）

**规则一：普通背包颜料被炸毁 → 加成随颜料一起销毁。**

强制完成把一枚普通背包颜料炸掉（地块变失色），恢复后是**全新空白地块，无任何
残留加成**。

**规则二：初始颜料的「范围」和「笔触效果」留在锚点地块上。**

举例：第 N 枚初始颜料是「怪物·幽灵」，调色目标=玩法，调色效果=提升1级，
笔触效果=堆砌·全图相同内容颜料提升2级。

1. 落下去 → 全图幽灵 +2；
2. 强制完成把它炸毁 → **地图上其他幽灵 -2**（因为锚点格上已经没有幽灵了）；
3. 失色恢复成空白，装一枚「存活」→ **全图存活玩法 +2**（笔触效果改挂到存活上）。

所以被炸毁的初始颜料，**范围和笔触效果都还在**。这就是 ``Tile.aura_amount`` 的
语义：强度挂在地块上，作用对象 = 「这一格当前那枚颜料」的同种颜料。

调色效果在不在，用户说「可能需要深挖，或者**暂定为在**」。当前实现按「在」处理
（加成已经兑现到目标颜料身上，不会因为来源颜料被炸而回退）。

**规则三：一枚初始颜料可以融合任意多套效果。**

用户 2026-11-23 截图口径（`C:\Users\8838\Desktop\jijiji`）：

| 情形 | 调色效果 | 笔触效果 | 颜料内容 |
|---|---|---|---|
| 1 枚初始颜料 | 1 | 1 | 1 |
| 2 枚融合 | 2 | 2 | **1** |
| 3 枚融合 | 3 | 3 | **1** |
| 放到虚空 | 还在 | 还在 | **没有** |
| 初始颜料盖在普通颜料上 | 1 | 1 | 1（**取地块原来那枚**） |

要点：

* **融合没有上限**，可以 3 枚、4 枚一直叠下去。
* **颜料内容永远只有 1 个**；调色效果和笔触效果可以有很多套。两者是独立的两套东西 ——
  放到虚空「只失去内容」但两套效果都还在，就是最直接的证明。
* **普通颜料只有内容**，不提供调色效果/笔触效果。所以初始颜料盖到普通颜料上，
  结果就是 1 调色 + 1 笔触 + 1 内容，不会因为底下原本有颜料而多出一套。
* **「笔触效果」不一定产生光环**。用户 2026-11-23：「笔触效果就是能放置在虚空，
  且失去自身内容」—— 那条笔触本身就是一条放置词缀，不存在「光环加给谁」的问题。
  只有「全图/范围内相同内容颜料额外提升N级」这类笔触才走 ``Tile.aura_amount``。
* **各条效果必须各自单独结算，不能取范围并集**（用户原话：「之前说的范围并集是错误的，
  因为可能作用颜料可能不一致需要单独计算」）。3 枚融合的实机例子：
  「2 条相邻怪物提升1级 + 1 条斜对角怪物提升1级」—— 相邻的两条各给上下左右范围内的
  怪物各 +1（合计 +2），斜对角那条只给四个角 +1。
* **完全重复的效果也要留着**：上面那个「2 条相邻怪物提升1级」就是两条一模一样的，
  各算一次。去重会少算等级。

### 「失去自身内容」到底失去谁的

用户 2026-11-23 的具体例子：

```
背包颜料 = 3 级宝箱
初始颜料 = 4 级怪物，调色效果 = 相邻范围玩法提升1级，
          笔触效果 = 放置到已放置颜料但失去自身内容
放上去之后 → 初始颜料【3 级宝箱】+ 相邻范围玩法提升1级 + 那条笔触效果
```

也就是**初始颜料自己的 4 级怪物内容丢了**，地块保留原来的 3 级宝箱；
初始颜料只贡献「调色效果 + 笔触效果」两套。

放虚空同理：失去的是初始颜料自己的内容，两套效果留着。

融合**不是配置里写死的**：``config_s8_gameplay_plotitem`` 的 ``EffectLibraryId`` 是单值、
``config_s8_gameplay_itemeffect`` 的 ``LibraryId`` 也是单值，一枚颜料在配置里只有一条
效果。融合是运行期把多套并起来的结果。用户原话：「相当于这个初始颜料融合了2种初始颜料」。

实现见 :class:`huahua_assistant.game_model.PaintEffect`、``CurrentPaintRule.effects``
和 ``Tile.retained_effects``。**并集只用于画面高亮 / 推荐计数**
（``_rule_scope_cells_for_anchor``），加成一律走逐条结算（``_apply_current_rule_upgrade``）。

### 和旧的「记地块」结论为什么不冲突

旧文档（2026-11-22）记的实机样本是「替换不影响加成」：颜料被改写（转成别的颜料）
后仍吃到此前积累的 +2/+1，显示 6 级。那不是反例 —— 改写内容时**颜料实例还在**，
加成当然跟着它走。

真正能区分两种记法的只有**销毁**：那时「记颜料」丢加成、「记地块」保留。用户
2026-11-23 给了销毁场景的口径（规则一），答案是**丢**。

## 代码现状（2026-11-23 改造后）

* ``Paint.bonus_level`` —— 颜料自己的等级加成，**所有来源共用这一个账**。
* ``Paint.bonus_parts`` —— 来源账 ``(来源, 级数)``，只供说明，不参与算术。
  常量 ``BONUS_SOURCE_RULE`` / ``BONUS_SOURCE_AFFIX`` / ``BONUS_SOURCE_AURA``。
* ``Tile.aura_amount`` —— 光环的**强度**，挂在锚点地块上，与颜料生命周期无关。
* ``Tile.retained_effects`` —— 被炸毁初始颜料留在地块上的效果包，供下一枚颜料继承（融合）。
* ``CurrentPaintRule.effects`` —— 效果清单，``direction``/``target_object``/``upgrade_amount``
  只是首条的便捷视图；``.directions`` 给并集范围用。
* ``game_model._carried_tile_buffs`` —— 帧间继承：**上一帧这一格有颜料**才继承
  那笔加成；断帧（失色/空白）就归零。不比较颜料种类，因为转化也要继承。
* ``game_model._tile_with_upgrade(as_bonus=True, source=...)`` —— 统一写
  ``Paint.bonus_level`` 并记账来源。
* ``level_reconcile._cover_intermediate`` —— 覆盖类笔触改内容不改实例，加成跟着走。
* ``game_model._randomize_scope_paints`` —— 同理，转化不丢加成。
* ``fast_vision._tile_buffs`` —— 回填快照时读 ``Paint.bonus_level``。
