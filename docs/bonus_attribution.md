# 加成到底记在「颜料」上还是「地块」上

这个问题反复出现，这里把每次实机证据和时间点记全，避免重复讨论。

## 结论（截至 2026-11-22）

**替换不影响加成，销毁未定。**

颜料被改写（等级变化 / 内容变化 / 被同等级颜料顶掉）时，它身上那几级的加成都还在。
模型目前把加成记在**地块**上（`Tile.bonus_level`），在这个场景下与「记在颜料上」
**行为完全一致**，因此不需要改。

唯一能区分两种记法的场景是**颜料被销毁**（不是替换）——那时「记颜料」会丢掉加成、
「记地块」会保留。用户明确说这条是悬案，尚未遇到可复现的局。

## 实机证据

### 2026-11-22 19:5x（同一局内，用户口述）
局面：遇到一枚 3 级初始颜料，词缀是「范围内转为同等级的颜料」，把两枚初始颜料
的等级都转化了。

* 其中一枚背包颜料**转化后依旧是 +3**；
* 左边的初始颜料显示：`相邻的玩法颜料提升1级` ×2 + `对角斜向的玩法颜料提升1级`，
  合计 +3，等级 6 = 3 + 3，与「3 级本体 + 3 级加成」吻合；
* 宝箱是 **+5**，没有受初始颜料被改变的影响。

→ 说明加成不随颜料的等级/内容改写而消失。

**注意**：这一段工具没有记录到——采集在 19:49:26 就停了（进程已退出），
用户描述的操作发生在之后。以上是用户口述，日志里查不到。

### 更早的观察
用户点开一枚已放置颜料，浮窗里列出的是**其它初始颜料给它的调色效果**
（`使横向的玩法颜料提升1级` / `使纵向的玩法颜料提升1级`），据此判断「加成记在颜料上」。
浮窗内容本身两种记法都会这样显示，不能单独定性。

### 2026-11-22 19:40 那局
`tile_buff_changed` 记到某格 `bonus_level 2→3`、该格 `level 6`，
说明模型的加成累加链路是通的。

## 代码现状

* `level_reconcile._cover_intermediate`：覆盖类笔触重算等级时
  `bonus = tile_bonus_level(keep)` —— **地块加成保留**，注释写明依据是
  「初始颜料的加成是加在地块上的，换一枚颜料这 N 级仍然在」。若这里清零，会出现
  模型算 3、画面 6 的对账红条。
* `game_model.state_from_observation`：锚点颜料读到的等级高于面板等级时，把差额
  记成 `bonus_level`（用户 2026-11-22 规则「初始颜料也是颜料」，r1c6 样本 3+3=6）。

## 待定

**销毁场景**。若遇到「加成来源的颜料被销毁」的局，要观察目标格等级是否掉回去：

* 掉回去 → 加成记在颜料上，`bonus_level` 要跟着颜料的生命周期迁移；
* 不掉 → 记在地块上，现在的实现就是对的。

在有这个观察之前，不要因为「浮窗里写着这些效果」就改成记颜料——替换场景下两者
表现一样，改了只会引入新 bug。
