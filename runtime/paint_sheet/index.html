画中雪原 · 颜料「图标 + 框」核对表

每个家族两行：背包透明底、白色地块压在实机空白可落子地块的浅色底上。 两处形状规则相同：怪物 = 圆形、 玩法 = 菱形。 框的颜色按等级固定：白绿蓝紫橙红彩 = Lv1~Lv7。 尺寸取解包出来的官方设置：UI 蓝图 S8Paint.uexp 里， 品质框 SizeBox 192、图标 SizeBox 128， 图标 ÷ 框 = 0.6667。 框素材画布带辉光留白（198~233），按各素材自己的画布换算成一个逻辑格。 早期从截图反推的「框要放大 1.30 倍」是错的——把实心环和含辉光外沿搞混了。 图标来自 PAK 解包（UI_S8Gameplay_Color*_128），框来自 S8 图集切片，均未从网页下载。 共 27 个家族。等级不是每个家族都通吃：赛季只有 Lv3/Lv4，黑潮/黑帆/魔方/迷城/梦魇/怪谈/玩偶只有 Lv5~Lv7（3~4 级时它是「赛季」颜料，升到 Lv5 才变成这些玩法颜料——「Lv1 迷城」这种组合游戏里不存在），缺的等级显示「—」。PAK 里确实解出了这些家族 Lv3/Lv4 的图标素材，但游戏内不会出现，所以按不存在处理；素材文件保留未删。
