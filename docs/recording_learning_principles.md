## 当前阶段

以记录模式为主，积累足够多、覆盖不同局面的高分样本后，再分析和学习。
现阶段不要求把数据组织成决策训练任务，不以点击证据或新增抽取轮次作为存档的前置条件。
记录棋盘、逐格颜料类别/家族/等级、初始颜料规则、笔触候选与能识别到的选择、背包和结果。
未识别字段保留未知；推断不提升为事实。记录模式继续关闭推荐计算。

## 连线的定义

- 类型仅分怪物、玩法，不要求具体家族相同，也不按等级分组。宝箱标记不另设第三类。
- 每条完整横线、纵线、两个斜向直线分别统计一次。
- 某类型可用格数 = 线上空白格数 + 该类型已安装颜料格数。
- 异类颜料占用自己的格子，但不把整条线分成左右两段。
- 虚空、阻挡、失色不算普通可用格；它们不切断同一条直线两侧的格子。
- 例：怪物、空白、玩法、空白、怪物、空白，怪物容量 5，玩法容量 4。
- 恰好 4/5/6 格分别计数，6 格线不拆出多个 4 格段；“至少 4 格”另存累计数。
- 不分类型的地块结构计空白 + 已安装颜料，只反映普通土地容量，不能代替分类型统计。
- 含类型未知/地形明细冲突的线保留容量上下界，不计入确定的“恰好 N 格”条数。
- 相邻、全图是另外两种调色作用范围，不强塞进 4/5/6 格直线条数。实际斜对角效果
  可能同时覆盖两个斜向，不能把两条线的统计直接当作某次效果的受益数量。
- 连线容量记录当前普通地块，不预测特殊词缀转换地形，也不等同于当下可点击的空位数。

## 未来学习的三项评价

1. 能否完成调色、让多少目标升级。
2. 能否增加 7 级宝箱或其他高价值颜料。
3. 会占用哪些关键空格，给后续留下多少空间。

学习高分局如何在这三项之间权衡，并在不同棋盘、初始颜料和笔触词缀下形成布局。
未来推荐应依据当时局面运用这些规律，不照搬历史坐标或固定操作顺序。
高分库用于研究高分思路；从中得到的出现频率只能称为高分样本内频率。

## 笔触与升级的复盘

- 面板效果原文保存在 `current.effect`；已知调色效果完整列表保存在 `current.effects`。
  融合的每条效果保留自己的方向、目标和升级量，顺序与重复项均保留。
  面板的调色效果不等同于选卡获得的笔触词缀。
- `brush.chosen` 只使用面板识别结果，不能拿界面默认第一张候选作为已选。
- 录制器独立记录短暂出现的卡片，在同一帧结果里携带累计事件；界面合帧不丢选卡信息。
  快照的 `recording_evidence` 带录制会话、事件序号、当时的颜料与锚点读数。
  点击与面板关闭、缓冲点击、效果反推分别保留来源；不把效果反推改成实际点击。
  `affix_card_clicked` / `affix_choice_resolved` 同时保存 `canonical_affix_id`、
  官方笔触表 `S8_Gameplay_SelectableEffect` 的 `brush_effect_ids`，唯一对应时另存
  `brush_effect_id`。同文案多个 ID 时单值留空、状态为 `ambiguous`，不取第一项冒充唯一值。
  ID 来自卡片文字与目录对应（`catalog_mapping`），不是从游戏协议直接读取；选择推断仍保留原来源。
  候选卡片的 `option_effects` 按原顺序保存 ID；无法对应则留空。旧档不补写这些字段。
  携带事件最多 256 条，截断会标记；完整事件仍追加到动作日志。
- 卡片点击优先按该帧的卡片矩形判断。空隙、确认区不作为卡片；缩放后不使用旧面板坐标回填。
- `observed_tiles` 保存画面识别到的等级和置信度，独立于模型基础等级、加成与光环。
- 复盘按上一帧的初始位置和每条调色效果，分别核对下一帧同类同家族颜料的等级。
  位置未确认、身份改变、低置信度或长间隔保留待核对；不能将读数上升直接归因于某条笔触。
  新安装前后身份与规则一致时，可采用安装后首次确认的位置。
- 旧档缺少词缀、截图或画面等级时不补猜。旧模型等级只作为基础等级对比，并明确注明。
- 源码更新需要正常重启一次录制工具；之后窗口缩放继续自动识别，不需要为每次缩放重启。
